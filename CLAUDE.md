# Working rules for this branch

These rules apply to work on `claude/determined-brahmagupta-sfwxww` and any branch built from it. `AGENTS.md` still applies.

- The instructor's class material stays as is: never modify the top-level `README.md`, `AGENTS.md`, `data/`, `src/`, `workshop/`, or anything on `main`.
- All new work is incremental: add new files or new versions, never overwrite earlier outputs.
- Each run writes to its own folder under `reports/` and publishes as a new artifact, never updating an earlier one.
- Before changing existing files, list them and wait for the user's OK.
